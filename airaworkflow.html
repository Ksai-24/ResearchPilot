Aira — Question → Answer Workflow

technical map with plain-English steps · numbered 1–6

The simple version

  • • 1 · You ask in the chat (type, speak, or attach a file)
  • • 2 · The server hands it to the agent loop
  • • 3 · The AI brain (OpenRouter) plans what to do
  • • 4 · Tools act: web search, page reading, safe code runs
  • • 5 · Evidence is gathered; the loop repeats (max 8 rounds)
  • • 6 · The final answer streams back with numbered sources

The loop, technically

  • • POST /api/ask → SSE event stream → run_agent(mode, depth)
  • • Tools per mode: RESEARCH = web_search + fetch_page; BUG_FIX adds run_python
  • • Fallback model chain + retry guards (agent.py)
  • • Old tool results elided to keep context small
  • • Guardrails: scratch-leak detection, auto-"yes" on permission asks

Stack & extras

  • • FastAPI + Uvicorn on :8000 · run.bat one-click start
  • • Single-file HTML/JS UI: history, mic (Web Speech), themes
  • • Uploads: PDF/DOCX → text, merged into your question
  • • Export chat → .docx / .pdf / .txt (python-docx, fpdf2)
  • • Free-tier throughout: OpenRouter free models, keyless DuckDuckGo
